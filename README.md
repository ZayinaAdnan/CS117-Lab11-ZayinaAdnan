# Storage Estimator - Main Version

## Purpose
A simple Python program that estimates the total storage needed for a group of files, based on the number of files and their average size in MB.

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run: `python storage_estimator.py`
4. Enter the number of files, then the average file size in MB.

## Example
Input:

```
Enter number of files: 10
Enter average file size in MB: 5
```

Output:

```
=== Storage Estimator ===
Total storage: 50.00 MB
```
